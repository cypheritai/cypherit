# CypherIt Roadmap 🗺️

Our mission: **Get anyone from "stuck" to "fixed" in 60 seconds.**

This roadmap is a living document. We ship fast and iterate based on what users actually need.

---

## ✅ Shipped

- [x] **Core Extraction** — YouTube URL → structured steps with timestamps
- [x] **Video Embeds** — Tap-to-play with segment looping
- [x] **Live Captions** — Synced to video playback
- [x] **Quick Info** — Tools needed, time estimate, warnings, pro tips
- [x] **Share Links** — Deep link directly to any step
- [x] **Mobile-First UX** — Scroll-snap, responsive, fast

---

## 🔨 Building Now

- [ ] **Popular Fixes Gallery** — Curated categories (Home, Tech, Phone, Auto)
- [ ] **Community Upvotes** — Surface the most helpful fixes
- [ ] **Multi-LLM Support** — Gemini, Groq, Ollama options

---

## 🔮 Coming Soon

- [ ] **Pro Tier** — Unlimited extractions, priority processing, no ads
- [ ] **Browser Extension** — Extract from any page you're viewing
- [ ] **Article Support** — Not just YouTube — blogs, docs, wikis
- [ ] **Affiliate Links** — Auto-link tools/parts (Amazon, Home Depot)
- [ ] **Mobile Apps** — Native iOS/Android wrappers
