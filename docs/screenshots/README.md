# Screenshots

This folder contains screenshots and GIFs for the README.

## Needed:
- `demo.gif` — Animated demo showing paste → extract → results
- `mobile.png` — Mobile view of the app
- `quick-info.png` — The Quick Info section with tools/warnings

## How to Capture:
1. Visit https://www.cypherit.ai
2. Use a screen recorder (Loom, Kap, etc.)
3. Record: Paste URL → Click "Get Steps" → Scroll through results
4. Convert to GIF and save as `demo.gif`
